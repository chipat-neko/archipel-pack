# L'Archipel brisé — packs de ressources du serveur

Fichiers téléchargés automatiquement par le jeu à la connexion au serveur (Minecraft Java 26.3).

- `archipel-pack.zip` : pack principal (obligatoire), SHA-1 `5d1f3b85f68f024c37e4040b59f1826aea6e253c`
- `archipel-ambiance.zip` : pack d'ambiance (facultatif, `/ambiance` pour le couper), SHA-1 `00fd24d1e0c388c6769925d6036051f79ce074b2`

Adresse réglée sur le serveur (console Crafty) :
`pack adresse https://raw.githubusercontent.com/chipat-neko/archipel-pack/main/archipel-pack.zip`
(le pack d'ambiance est trouvé tout seul à côté).

Si un module change ses fichiers de pack, l'empreinte change : il faut remettre ici le nouveau zip
(`plugins/ArchipelSocle/archipel-pack.zip` ou `plugins/ArchipelAmbiance/archipel-ambiance.zip` du serveur).
